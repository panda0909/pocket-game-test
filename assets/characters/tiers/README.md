# 吉祥物階級裝備展示

這裡保存以原始吉祥物模型為基礎的四階裝備進化展示圖。原始角色仍保留在
上層 `assets/characters/`，本資料夾不覆蓋原始 PNG。

| 角色 | 展示圖 | 裝備方向 |
|---|---|---|
| 紅牛 | `red_bull_tiers.png` | 重擊錘、護肩、重型胸甲、金紅衝擊能量 |
| 壁虎 | `gecko_tiers.png` | 通訊器、雙持能量槍、護目鏡、青橘高速能量 |
| 恐龍 | `dino_tiers.png` | 藤葉護具、自然晶體、範圍能量核心、綠金光環 |

每張圖由左至右為第 1～4 階。角色的臉部、身體比例、主色與原始辨識特徵
保持不變，差異集中在可穿戴裝備、武器、核心與能量效果。

這些目前是四階展示 sheet；遊戲由 `UnitView` 使用 `AtlasTexture` 依 tier 載入
對應區塊，不另複製四張 PNG。原始角色圖仍保留作為載入失敗時的安全 fallback。
